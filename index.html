📄 隐私政策与用户同意

欢迎使用本系统。使用前请阅读以下说明（要点）：

  • 我们收集的信息：你的钉钉身份（unionId、昵称）、填写的日报/周报/月报内容，以及你配置的 AI 模型 API Key。
  • 用途：用于身份识别、生成与共享团队日报，以及调用 AI 生成周报/月报。API Key 仅用于为你本人生成报告，已加密存储。
  • 数据分级：日报内容可能包含客户、项目与商业秘密，属内部受限数据，仅你本人、你的直属上级与管理员可见。
  • 留存与共享：数据存储于企业云端（Supabase），按权限最小化访问，不会向无关第三方提供。
  • 你的权利：你可随时修改或删除自己的日报；你配置的 API Key 可随时清除。

依据《个人信息保护法》《数据安全法》，点击「同意」即表示你已知悉并同意上述收集与处理方式。
